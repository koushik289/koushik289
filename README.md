# Koushik Inampudi

iOS developer and web builder based in Melbourne, Australia. I build real apps that solve real problems — live parking data, transit disruption tracking, and sports scores.

---

## Projects

### [MelbPark](https://github.com/koushik289/MelbPark) — iOS
Real-time Melbourne CBD parking tracker. Live sensor data from 10,000+ on-street bays, filterable by time limit and cost, with MapKit navigation.  
`Swift` `SwiftUI` `MapKit` `MVVM` `XcodeGen`

### [VicAlert](https://github.com/koushik289/vicalert-ios) — iOS
Victoria energy outage and public transport disruption tracker. Live outage map by postcode, PTV service alerts, and disruption-aware trip planning.  
`Swift` `SwiftUI` `MapKit` `MVVM` `PTV API`

### [Sportline](https://koushik289.github.io/sports-tracker) — Web
Live scores, standings, stats leaders and awards for NBA, NFL, and MLB. Favourites system, live scores strip, no frameworks.  
`HTML` `CSS` `Vanilla JavaScript`
