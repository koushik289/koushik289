# Wedding Run-up

A phone-first planner for the 25 November wedding: countdown, dated checklist and an idea dump.

- `index.html` is the page source. It is published as a private Claude artifact, which hosts it and stores the data.
- Tasks and ideas are saved in the artifact's own database, so they sync across devices. They are not stored in this repository.
- There is no build step, no CI workflow and no deploy job, so nothing here sends email.
